## 🚀 Quick Start

### Prerequisites

Before you begin, ensure you have the following installed:

| Requirement | Version | Check Command |
|-------------|---------|---------------|
| Node.js | 18+ | `node --version` |
| npm | 9+ | `npm --version` |
| Git | Latest | `git --version` |

### Installation

<details open>
<summary><strong>📦 Step-by-step Installation</strong></summary>

**1️⃣ Clone the repository**

```bash
git clone https://github.com/yourusername/ogo-manager.git
cd ogo-manager
```

**2️⃣ Install dependencies**

```bash
# Using npm
npm install

# Or using yarn
yarn install

# Or using pnpm
pnpm install
```

**3️⃣ Set up environment variables**

```bash
# Copy the example environment file
cp env.example .env.local

# Edit with your Supabase credentials
```

**4️⃣ Start the development server**

```bash
npm run dev
```

**5️⃣ Open in browser**

```
🌐 http://localhost:5173
```

</details>

### Environment Setup

Create a `.env.local` file in the root directory:

```env
# 🗄️ Supabase Configuration
VITE_SUPABASE_URL=your_supabase_project_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key

# 🔐 Optional: Admin Email
VITE_ADMIN_EMAIL=admin@ogo.technology
```

<details>
<summary><strong>🗄️ Database Setup</strong></summary>

Run the following SQL files in your Supabase SQL Editor:

```bash
# 1. Main database schema

# 2. Projects table

# 3. Employee payments migration
DB/migration_employee_payments.sql

# 4. Analytics comparison table
DB/analytics_comparison_table.sql

# 5. Export reports table
DB/export_reports_table.sql
```

</details>

<details>
<summary><strong>📝 Table Definitions</strong></summary>

```sql
-- 👥 Employees Table
CREATE TABLE employees (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    employee_id VARCHAR(50) UNIQUE NOT NULL,
    first_name VARCHAR(100) NOT NULL,
    last_name VARCHAR(100) NOT NULL,
    position VARCHAR(100),
    birthday DATE,
    address TEXT,
    whatsapp_number VARCHAR(20),
    email_address VARCHAR(255),
    qualifications TEXT,
    created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 📋 Projects Table
CREATE TABLE projects (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    project_id VARCHAR(50) UNIQUE NOT NULL,
    client_name VARCHAR(255) NOT NULL,
    client_uni_org VARCHAR(255),
    project_description TEXT,
    deadline_date DATE,
    price DECIMAL(10,2) DEFAULT 0,
    advance DECIMAL(10,2) DEFAULT 0,
    balance DECIMAL(10,2) DEFAULT 0,
    assigned_to TEXT,
    payment_of_emp DECIMAL(10,2) DEFAULT 0,
    employee_payments JSONB,
    status VARCHAR(20) DEFAULT 'Running' 
        CHECK (status IN ('Running', 'Pending', 'Pending Payment', 'Delivered', 'Correction', 'Rejected')),
    fast_deliver BOOLEAN DEFAULT FALSE,
    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW()
);
```

<summary><strong>▲ Deploy to Vercel</strong></summary>

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/yourusername/ogo-manager)

**Manual Deployment:**

```bash
# Install Vercel CLI
npm i -g vercel

# Login to Vercel
vercel login

# Deploy
vercel --prod
```

**Environment Variables:**

Add these in Vercel Dashboard → Settings → Environment Variables:

| Variable | Value |
|----------|-------|
| `VITE_SUPABASE_URL` | Your Supabase URL |
| `VITE_SUPABASE_ANON_KEY` | Your Supabase Anon Key |

</details>

<details>
<summary><strong>🔷 Deploy to Netlify</strong></summary>

[![Deploy to Netlify](https://www.netlify.com/img/deploy/button.svg)](https://app.netlify.com/start/deploy?repository=https://github.com/yourusername/ogo-manager)

## 🤝 Contributing

We love contributions! 💖

<details>
<summary><strong>📝 How to Contribute</strong></summary>

1. **Fork** the repository
2. **Clone** your fork
   ```bash
   git clone https://github.com/yourusername/ogo-manager.git
   ```
3. **Create** a feature branch
   ```bash
   git checkout -b feature/amazing-feature
   ```
4. **Commit** your changes
   ```bash
   git commit -m '✨ Add amazing feature'
   ```
5. **Push** to the branch
   ```bash
   git push origin feature/amazing-feature
   ```
6. **Open** a Pull Request

</details>

<details>
<summary><strong>📋 Commit Convention</strong></summary>

| Emoji | Type | Description |
|:-----:|------|-------------|
| ✨ | `feat` | New feature |
| 🐛 | `fix` | Bug fix |
| 📝 | `docs` | Documentation |
| 💄 | `style` | UI/Style changes |
| ♻️ | `refactor` | Code refactoring |
| ⚡ | `perf` | Performance |
| 🔧 | `chore` | Maintenance |

</details>
