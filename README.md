<h1 align="center">🚀 OGO Manager</h1>

<p align="center">
  <b>OGO Manager</b> is a modern, full-stack <b>Project & Employee Management System</b> built for <b>Ogo Technology</b>.<br>
  It delivers <b>real-time project tracking, financial insights, and performance analytics</b> — all inside a secure, responsive, and user-friendly interface.
</p>

<h2>🎯 Key Features</h2>

<ul>
  <li><b>🔐 Secure Authentication</b><br>Powered by Supabase with PostgreSQL & Row Level Security (RLS). Session management with auto-expiry & activity logging.</li>
  <li><b>📊 Dashboard & Analytics</b><br>Real-time revenue, employees, and project data. Dynamic filters with interactive charts (Chart.js & Recharts).</li>
  <li><b>📅 Calendar Module</b><br>Monthly project deadlines, color-coded statuses, and overdue indicators.</li>
  <li><b>👥 Employee Management</b><br>CRUD operations, performance metrics, and advanced search & filters.</li>
  <li><b>📁 Project Management</b><br>Full lifecycle, client/financial details, deadline tracking, and PDF receipts.</li>
  <li><b>📝 Reporting</b><br>Financial & employee analytics with exportable PDF reports (jsPDF & HTML2Canvas).</li>
  <li><b>⚙️ System Settings</b><br>Configurations, user preferences, backup & restore.</li>
  <li><b>📱 Responsive & Accessible</b><br>Glassmorphism UI, dark theme, mobile-first design, and accessibility compliance.</li>
</ul>
